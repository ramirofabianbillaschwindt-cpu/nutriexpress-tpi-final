# NutriExpress S.R.L.

Trabajo Práctico Integrador de Organización Empresarial — Tecnicatura Universitaria en Programación, UTN.

**Integrante:** Ramiro Billa Schwindt.

## Proyecto
Diseño de un módulo de inventario y planificación de demanda para una empresa ficticia de viandas saludables. Vincula pedidos, recetas, insumos, lotes y movimientos para anticipar compras y controlar existencias y vencimientos.

## Declaración de uso de IA
Se utilizó ChatGPT y Codex como apoyo y copiloto para consultar conceptos, explorar alternativas y preparar y revisar borradores, diagramas y documentación. Las propuestas se contrastaron con las consignas y con el caso NutriExpress.

La revisión permitió ajustar la clasificación interna y externa del FODA, distinguir los plazos de construcción de las mediciones operativas y comprobar la coherencia del BPMN con los datos. El contenido y su defensa quedan bajo responsabilidad del estudiante. La autorrevisión del trabajo individual contó con apoyo de IA y no representa la participación de un revisor externo.
