# Diagramas BPMN

- [Vista en PDF](Diagrama_BPMN_NutriExpress.pdf): proceso principal y abastecimiento.
- [Modelo editable](nutriexpress-produccion.bpmn): BPMN 2.0 validado contra el esquema oficial.

Los pools distinguen NutriExpress del proveedor externo; las lanes distribuyen responsabilidades. Las líneas continuas son secuencias internas y las discontinuas son mensajes entre participantes. El modelo contempla faltantes, rechazo de recepción, cambios de stock y fallos de registro.

El modelo es descriptivo; no representa una aplicación implementada.
